## Utrzymanie SDK 1.2.3 — czat, RPL i UX

Czat współdzieli z pytaniami limit 20 wywołań co najmniej co 10 s, 2048 output tokens i timeout45 s w jednej stałej opłacie sesji. Pending zachowuje fence/rezerwację bez paid auto retry. Historia/odpowiedzi/propozycje czatu są memory-only, durable marker/HMAC/klucz/czas bez treści; replay nie odtwarza odpowiedzi. Bez zgody host nie przekazuje transkryptu, mikrofon nie blokuje czatu po autoryzacji karty. Host waliduje propozycje i źródła, AI nie zapisuje; accept używa istniejącego guarded PATCH. Patient-scoped RPL candidates są autoryzowane/no-store; użytkownik wybiera produkt i osobno akceptuje listę, no-hit wymaga potwierdzenia nazwy bez zmyślonego ID. STT słownik tylko w obsługiwanym bezpośrednim OpenAI prompt, bez nieobsługiwanych OpenRouter options/retry; fonetyczne korekty do potwierdzenia z raw evidence. Trzy zakładki, sticky composer, trzy najnowsze pytania/wzmianki plus wcześniejsze disclosure; timer/STOP bez fali. Zachowaj niezależne domeny AI, natywne szkice, grants i stare wheels. Pełny kontrakt: [PLUGIN_LIVE_INTERVIEW_CONTRACT.md](PLUGIN_LIVE_INTERVIEW_CONTRACT.md). SDK1.2.3 addytywne chat callbacks bez nowych migracji/grantów/workera; rzeczywisty provider/mic/MariaDB odbiór osobny.

## Clinic activation contract — established documentation copy

**Ustawienia → Wtyczki** precedes **Ustawienia AI**. Active local clinic administrators see all healthy, globally enabled exact-approved modules, including local OFF and AI-not-ready entries. The independent clinic module gate applies to no-AI and AI plugins across operational UI/runtime/replay and new queue/event work. AI plugins additionally need explicit clinic AI consent and existing grants/configuration/entitlement/credit checks; module activation grants none of these. Missing rows default ON only in an existing activation schema; missing schema/DB state fails closed. The host administrator reviews only missing migration 089; partners do not execute host SQL or import private gates.

OFF retains AI consent, guide progress and stored data, hides operational UI and denies subsequent work, without promising cancellation of in-flight requests/provider dispatch or financial refunds. Confirmed settings changes remove matching module wrappers; uncertain writes require explicit reload rather than automatic retry. The guide preserves `clinic_admin:v1` and its original six IDs, adds `ai`/`plugins` as steps seven/eight, and uses the „Pierwsze kroki” disclosure (open while incomplete, closed after all eight acknowledgments). See the partner development/API/style contracts. This update adds no private host deployment guide or source to the public repository; static documentation review is not production acceptance.
